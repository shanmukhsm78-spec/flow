FLOW is a privacy-first prototype: chat and memory run on your machine via Ollama. No cloud ownership of your chats by this app. Not a finished product — an honest v0.

Stage: idea / early prototype · Powered by local Ollama

Today you can run a local chat UI that talks to Ollama on your laptop and saves conversation history plus small notes to a local memory.json. That’s what ships. Ambition is larger; the build is not there yet.

Runs on your machine

Chat goes to a local Ollama instance (default 127.0.0.1:11434). You install and run the model.

Local memory.json

Messages and small notes persist in a project-local file. You can open, copy, or delete it anytime.

No cloud chat ownership

This app does not send your chats to a FLOW cloud. Replies come from whatever model you run locally.

Ghost / Silence Mode Experimental

Stub only in v0. Toggle exists in the app UI; it does not implement real silence or stealth behavior yet.

What we are not claiming

  • Does not “remember everything” or learn what you care about automatically
  • Does not notice when you’re stuck or quietly offer help
  • Not a polished offline product — you need Ollama running
  • Ghost / Silence Mode is an experimental stub, not shipped
